# Capstone Tailwind CSS – Nhóm 2

Dựng lại trang Home của template [Solid](https://solid.nextjstemplates.com) bằng **HTML + Tailwind CSS**, có responsive, dark mode và hiệu ứng giống mẫu.

## Công nghệ

- HTML, Tailwind CSS v4 (CDN)
- Flowbite v3: menu dropdown, popup tìm kiếm, accordion, tab
- Swiper: slider phần Testimonial
- WOW.js + Animate.css: hiệu ứng khi cuộn trang
- Font Awesome (icon), font Inter (Google Fonts)
